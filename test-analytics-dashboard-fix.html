🐛 Root Cause Analysis

Primary Issue: The useTimeFilter composable was being used incorrectly in two places:

1. OverviewCards.vue (Line 133) 
// ❌ BEFORE (Incorrect)
const { currentFilterLabel } = useTimeFilter(props.timeFilter)
const timeFilterLabel = computed(() => currentFilterLabel.value)

// ✅ AFTER (Fixed)
const { timeFilterOptions } = useTimeFilter()
const timeFilterLabel = computed(() => {
  const option = timeFilterOptions.find(opt => opt.value === props.timeFilter)
  return option?.label || 'All Time'
})
2. AnalyticsDashboard.vue (Line 187) 
// ❌ BEFORE (Incorrect)
const { currentTimeFilter, setTimeFilter } = useTimeFilter()

// ✅ AFTER (Fixed)
const { timeFilter: currentTimeFilter, setTimeFilter } = useTimeFilter()
