# Paano Gamitin ang CFAS System Launcher

## Nag-create na ang Desktop Shortcut! ✓

Nag-success na ang shortcut creation. Makita mo na sa desktop ang:

**"CFAS Exam System"** icon

## Paano I-launch ang System

### Dali lang - 2 steps:

**Step 1:** Double-click ang "CFAS Exam System" icon sa desktop

**Step 2:** Mag-gwa ang professional GUI window:
- May CFAS logo sa taas
- May list sang services nga mag-start
- May green button nga "🚀 START SYSTEM"
- May gray button nga "CANCEL"

**Step 3:** Click ang green "🚀 START SYSTEM" button

**Step 4:** Mag-start na automatic:
- Apache Web Server (33%)
- MySQL Database (66%)
- Laravel Backend API (100%)

**Step 5:** Mag-open automatic ang browser sa exam system!

## Kung May Problema

### Wala gid nag-gwa nga GUI
- Check kung nag-exist ang XAMPP sa C:\xampp
- Check kung nag-exist ang backend folder

### Services wala nag-start
- Check kung available ang ports 80, 3306, 8000
- Check kung nag-install ang PHP

### Browser wala nag-open
- Manual lang i-open: http://192.168.11.40/exam-frontend
