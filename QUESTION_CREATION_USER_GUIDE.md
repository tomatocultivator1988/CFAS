# Question Creation - User Guide

## How to Create Questions (English)

### Method 1: From Question Management Page

1. **Go to Question Management**
   - Click "Question Bank" in the sidebar
   - Click "Create Question" button

2. **Fill in Question Details**
   - Enter your question text
   - Add answer choices
   - Mark the correct answer

3. **NEW: Select Exam (Optional)** 🆕
   - You'll see a dropdown: "Attach to Exam (Optional)"
   - **Option A**: Select an exam from the list → Question will be added to that exam
   - **Option B**: Select "No Exam (Create as unassigned)" → Question saved for later use

4. **Click Create**
   - Done! Question is saved and attached to the selected exam

### Method 2: From Exam Detail Page

1. **Go to Exam Management**
   - Click "Exam Management" in the sidebar
   - Click on an exam to open details

2. **Add Questions**
   - Click "Add Questions" button
   - Fill in question details
   - Click "Save All Questions"

3. **Automatic Attachment**
   - Questions are automatically attached to this exam
   - No need to select exam (it's already selected)

## Troubleshooting

### "I created a question but can't find it in my exam"
**Solution**: When creating from Question Management, make sure you selected the exam in the dropdown. If you selected "No Exam", the question is saved as unassigned.

### "Where are my unassigned questions?"
**Solution**: Go to Question Management → All your questions are there. Unassigned questions can be attached to exams later from the Exam Detail page.

### "Can I change which exam a question is attached to?"
**Solution**: Currently, you need to delete the question from one exam and add it to another. A "move question" feature may be added in the future.
