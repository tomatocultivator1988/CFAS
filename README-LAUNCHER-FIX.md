# CFAS Launcher - Terminal Auto-Close Fix 🔧

## Quick Start

### Problem
Terminal closes automatically when running launcher, can't see what's happening.

### Solution
Run this one command:
```
Double-click: FIX-LAUNCHER-NOW.bat
```

That's it! The fix will be applied automatically.
